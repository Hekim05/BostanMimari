# Bostan Mimarı

Kent bostanı kasa kurulum planlayıcısı (PWA) — Kent Tarım Birimi.

- Kasa grupları: I / L / U şekil, malzeme kasası (içte bölmeli ya da dışta ek), ahşap / kompozit / galvaniz / briket
- Teknik çizim: vaziyet planı, kasa kesiti, yan görünüş, köşe detayı, malzeme kasası detayı, sulama şeması
- Damla sulama hesabı ve malzeme listesi, toprak karışımı miktarları
- Denetim (mimar ajanı), 3D görünüm + saha fotoğrafı üstüne yerleştirme, A4 rapor

Yayın: https://hekim05.github.io/BostanMimari/
